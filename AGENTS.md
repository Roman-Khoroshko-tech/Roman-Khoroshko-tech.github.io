# Правила роботи Codex

- Мова інтерфейсу й документації – українська. Використовуй тире «–».
- Це окремий портал. Не змінюй репозиторії інструментів заради змін каталогу.
- Стек: HTML, CSS, ES modules, JSON. Без сервера застосунку, трекерів, CDN та фреймворків без обґрунтованої потреби.
- Каталог змінюй тільки через tools.json. Статуси: ready, beta, development, planned. URL – HTTPS або null; ready/beta потребують чинної адреси.
- Не позначай інструмент доступним, доки його опубліковану адресу не перевірено.
- Не додавай персональні дані, документацію клієнтів, паролі, токени або внутрішні корпоративні файли.
- Поля JSON вставляй у DOM через textContent; SVG допускаються лише з фіксованого локального переліку.
- Ресурси мають використовувати відносні шляхи. Перевіряти також публікацію в підкаталозі.
- Перед commit: npm test і npm run build. Для зміни UI: браузер, пошук, теми, клавіатура, ширини 390/768/1440, відсутність горизонтального переповнення.
- Критичні зміни – окрема гілка, PR, успішний CI перед merge. Не вимикай перевірки задля публікації.
- Перед поверненням версії перевір git status, збережи незакомічені зміни; використовуй git revert без force push.
- Оновлюй CHANGELOG.md для функціональних змін і README.md при зміні процесу роботи.

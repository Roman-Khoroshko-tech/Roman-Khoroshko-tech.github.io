# MFC710 RS Monitor

Браузерний монітор для перетворювачів частоти TWERD MFC710. Підтримує графіки, діагностику, керування через Modbus RTU та роботу з картами параметрування.

## Запуск

Відкрийте `index.html` у настільному Chrome або Edge. Режим «Демо» дозволяє перевірити інтерфейс і графіки без ПЧ.

Для підключення потрібні USB–RS-485 адаптер і браузер із Web Serial. Опубліковану сторінку відкривайте через HTTPS. Укажіть адресу, швидкість і параметри послідовного порту відповідно до налаштувань ПЧ, натисніть «Підключити» та виберіть порт адаптера.

Команди пуску й запису потребують дозволу в інтерфейсі та відповідних налаштувань ПЧ. Штатний контур аварійної зупинки працює окремо від браузера.

## Карта параметрування

- JSON – резервна копія вихідних слів Modbus. Після імпорту порівняйте карту з підключеним ПЧ. Відновлення доступне для параметрів із підтримуваним форматом запису.
- Word і CSV – звіти для перегляду. Для документованих форматів програма показує фізичні величини, режими й джерела PCH.

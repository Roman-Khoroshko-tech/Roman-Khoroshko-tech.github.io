Налаштування MFC710 для керування через RS
Підключення
4.8 – швидкість, 4.9 – адреса Modbus. У моніторі введи ті самі значення.
Дозвіл RS
4.7 – вибери потрібний сигнал дозволу. 007 Sw.On означає постійний дозвіл; застосовуй його лише там, де це передбачено схемою керування.
Пуск / стоп
2.4 = 032 для A або 2.5 = 032 для B.
Частота й напрямок
2.2 = 139 для A або 2.3 = 139 для B. Перевір режим 1.20, межі 2.11 / 2.12 і 1.40 та дозволений напрямок 1.65.
Задатчик ПІД
2.60 = 142. Для керування частотою від ПІД – 2.2 = 137 або 2.3 = 137 та налаштований вхід зворотного зв’язку 2.61.
Перемикання A/B
На OP‑11 обери для 2.1 вільну PCH.384–447 (за потреби 4.6 = 001 Full PCH). Монітор перевіряє призначення. Для перемикання з монітора в обох каналах має бути вибрано пуск через RS (2.4 = 2.5 = 032).
Стоп і втрата RS
Перевір спосіб штатної зупинки 1.64, реакцію і час втрати зв’язку 3.60 / 3.61. Скидання аварії, блокування й примусове керування через RS потребують дозволу 4.7.

Читання та доступні зміни параметрів – у панелі «Параметри ПЧ» під трендами.

Параметри ПЧ
Номери від 0.1 до 6.255. Можна запитати параметр поза списком.

Редагування доступне після зупинки ПЧ, зняття команди пуску й увімкнення «Дозволити команди з браузера». Параметри без підтвердженого формату запису доступні для читання.

Карта параметрування

Відмінності параметрів

    Примусове керування RS

    Тестове заміщення DI ігнорує фізичні сигнали. Режим доступний лише за активного блокування RS та зупиненого привода. Для запуску спочатку поверни фізичні входи, потім зніми RS-блокування.

    Підтвердити запис параметрів

    Переконайся, що команди пуску знято з усіх джерел.

      Підключення й перша перевірка

      1. Відкрий файл у настільному Chrome або Edge. USB–RS‑485 адаптер має бути доступний у Windows як COM-порт.
      2. Введи швидкість із параметра 4.8 та адресу з 4.9. Формат 8 біт, без парності, 2 стоп-біти (8N2). Натисни «Підключити» й вибери порт.
      3. Монітор прочитає регістр 2006, щоб перевірити відповідь ПЧ. Звір «Робота» та інші індикатори з OP‑11. Прочитай 40004 на початковому графіку «Вихідна частота» і звір з параметром 0.4 на OP‑11. Для сирого слова встановлюй множник і знак лише після підтвердження формату; звір у кількох сталих точках.

      Керування через RS

      Монітор перевіряє дозвіл RS і активні джерела за станом ПЧ. Пуск і стоп змінюють біт 15 регістра 2000, скидання формує імпульс бітом 1. Блокування використовує біти 12–14. У 2001 записується завдання зі знаком: Гц для U/f, об/хв для векторного режиму. Зміна напрямку доступна після зупинки. Задатчик ПІД записується в 2002. Перемикання A/B записує 0 або 1 лише в RS-точку, вже призначену параметром 2.1. Підтвердження запису звіряється окремим читанням.

      Кнопка «Стоп» передає штатну команду RS. Для аварійної зупинки використовуй штатний контур шафи. Перед стендовою перевіркою узгодь реакцію ПЧ на втрату RS за 3.60/3.61. Скидання аварії виконуй після усунення причини й зняття команди пуску.

      Карта параметрування

      JSON містить зчитані слова груп 1–6 і версію ПЗ. Word містить звіт за групами, CSV – таблицю для Excel. Після відкриття JSON порівняй карту з підключеним ПЧ й переглянь список змін. Записуються лише відмінні параметри з підтримуваним форматом запису. Звіт про зчитування відокремлює відсутні регістри від помилок обміну.

      Регістр та шкала

      У налаштуваннях сигналу вимкни «Автомасштаб», щоб зафіксувати межі графіка. «Окрема вісь Y зліва» показує поділки кольором відповідної кривої. Для PCH з визначеним форматом застосовується масштаб з додатка A. Для програмованих точок і копій сигналів зі змінним форматом можна вручну задати множник і одиницю.

      Адреси в кадрі FC03 беруться з карти MFC710. Приклади 2006, 1151 і 40004 передаються як числові адреси, без віднімання 1 або 40001. Якщо ПЧ відповідає винятком, його код і адресу видно під статусом. Стани готовності, роботи, аварії й попередження беруться з PCH.061–063 та PCH.065. Коди подій читаються з PCH.206 і PCH.207, описи – за таблицею 6.1.

      У «Налаштуваннях шкали» кожного сигналу межі задають видимий діапазон, а множник перераховує покази. Для сирих слів вихідної частоти та уставки за замовчуванням використовується 0,1 Гц за відлік (500 → 50 Гц). Якщо показ OP‑11 відрізняється, зміни множник. Якщо для параметра задано множник групи 0, він замінює автоматичний множник сигналу.

      Для групи 0 додаток C визначає фізичні одиниці, а формат сирого слова для цих регістрів не уточнений. Множник і знак можна задати вручну після звірки. Після зміни формату історія сеансу очищується, щоб не змішувати шкали. У демо фізичні одиниці задає модель симуляції.

      Автоматичний інтервал фіксований для поточного набору сигналів та швидкості RS‑485. Розрахунок враховує блоки регістрів і запас на відповідь ПЧ. Тайм-аути, запис команд і зчитування параметрів можуть затримати оновлення. Якщо значення не отримано, на графіку буде розрив. Історія в пам’яті обмежена 12 000 циклами.

# Перевірка порталу – 20.11.2026

- Node.js: 6/6 тестів каталогу, валідації, пошуку, статусів і HTTPS-адрес пройшли.
- npm run build формує тільки дозволені публічні файли.
- Chrome, опублікований сайт: пошук MFC710 і «діагностика», порожній результат, статус «Заплановані», категорія HMI – перевірено.
- Темна тема вмикається й зберігається після reload. Світла тема перевірена під час першого відкриття.
- Розміри браузера: 390×844, 768×1024, 1440×900. Горизонтального переповнення немає: scrollWidth відповідно 375, 753, 1425 px (вужче за innerWidth через смугу прокручування). На планшеті й ПК – дві колонки; на смартфоні – одна.
- Редактор відкрився за власною Pages-адресою; відобразив український інтерфейс, каталог 49 функцій і посилання на портал. CI редактора: check і deploy успішні.
- Повний набір браузерних тестів редактора не запускався; його штатні 145 перевірок у 19 наборах пройшли локально. Інтеграція не змінює алгоритми ПЛК.
- Валідація некоректної конфігурації перевірена автоматично. UI відновлення після мережевої помилки реалізований, але примусова мережева помилка в опублікованому середовищі не відтворювалася.
- Локальний HTTP-перегляд у цьому сеансі обмежений мережевою ізоляцією; UI перевірено на реальній Pages-публікації. Локальні Node.js-перевірки та збірка доступні без мережі.
